Añadir links de todos los .html de la ruta a: index.html

⠀ - Busca recursivamente todos los archivos .html y:

⠀ ⠀ Los añade al final de index.html como links <a> dentro de un <li> y separados con <br>

⠀ ⠀ Los nombra como:' - Ejercicio 1', ' - Ejercicio 2', ...

        - Ejemplo:
        
            <br>
            <li><a href="ruta/Ejemplo1/ejemplo1.html"> - Ejercicio 1</a></li>
            <br>
            <li><a href="ruta/Ejemplo2/ejemplo2.html"> - Ejercicio 2</a></li>
        
        - Código:
        
            n=0
            echo "" >> index.html
            echo "<!-- Inicio del script -->" >> index.html
            for i in $( sudo find $(pwd) -type f -iname "*.html" ); do
                n=$((n+1))
                echo "<br>" >> index.html
                echo "<li><a href=\"$i\"> - Ejercicio $n</a></li>" >> index.html
            done

Copy:

n=0; for i in $( sudo find $(pwd) -type f -iname "*.html" ); do n=$((n+1)); echo "<br>" >> index.html; echo "<li><a href=\"$i\"> - Ejercicio $n</a></li>" >> index.html; done
